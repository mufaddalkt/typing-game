# Typing Game

A typing game where a plane keeps flying as you type words correctly. Type fast and accurately to keep the plane airborne — miss too many and it crashes.

## Play

Open `index.html` in a browser, or enable GitHub Pages on this repo for a playable link.

## Features

- 3 difficulty presets (Calm / Cruise / Storm) with adaptive word length based on your rolling WPM
- Live WPM, accuracy, distance, streak, and lift stats
- Low-lift "PULL UP!" warnings, lift-gain popups, visible crash dive animation
- Trouble-word drill rounds targeting the words you miss
- Sound effects with mute toggle, streak glow, screen shake, 3-2-1 countdown
- Pause / resume (auto-pauses when the tab loses focus), restart, recent-word log, end-of-flight summary
- Light and dark mode, responsive mobile layout
