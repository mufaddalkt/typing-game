# Typing Game

A typing game where a plane keeps flying as you type words correctly. Type fast and accurately to keep the plane airborne — miss too many and it crashes.

## Play

Open `index.html` in a browser, or play the hosted version.

## Features

- 3 difficulty levels
- Live WPM, accuracy, distance, streak, and lift stats
- Pause / restart, recent-word log, end-of-flight summary
- Light and dark mode
